# HP Framework Documentation

HP Framework is organized around explicit VContainer lifetimes. During active development, runtime/editor code, Bootstrap and default settings are kept together under `Assets/Plugins/HPFramework`.

Current documentation reflects the non-destructive Setup/Repair workflow, optional Input System integration, URP Base/Overlay UI camera stacking, scoped EventBus architecture, optimized pooling/persistence/resources behavior, Safe Area integration, and BasePopup edit-mode animation preview.
